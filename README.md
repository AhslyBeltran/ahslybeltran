## ✨ Descripción

Portafolio personal con una estética futurista que simula entrar a una estación espacial. Fondo de espacio profundo con estrellas, nebulosas, planetas flotantes y partículas en movimiento, manteniendo un aspecto profesional apto para un portafolio laboral.

## 🛰️ Características

- 🌌 Fondo oscuro tipo espacio profundo
- ⭐ Estrellas generadas dinámicamente con JavaScript
- 🌫️ Nebulosas sutiles en azul, morado y cian
- 🪐 Planetas y órbitas flotantes
- ✨ Efectos de brillo y partículas ascendentes
- 🎨 Tipografía futurista (Orbitron) + limpia (Rajdhani)
- 📱 Diseño 100% responsive (computador, tablet y celular)
- 🧭 Barra de navegación fija con menú hamburguesa en móviles
- 👀 Animaciones de revelado al hacer scroll con `IntersectionObserver`
- 🖱️ Efectos hover elegantes y scroll suave

## 🛠️ Tecnologías

- **HTML5** — Estructura semántica
- **CSS moderno** — Animaciones, grid, responsive y efectos
- **JavaScript vanilla** — Sin frameworks
- **Font Awesome** — Iconografía
- **Google Fonts** — Orbitron y Rajdhani

## 🗂️ Estructura del proyecto

```
portafolioGithub/
├── index.html          # Estructura principal del sitio
├── css/
│   └── style.css       # Estilos y tema espacial
└── js/
    └── portafolio.js   # Estrellas, partículas y animaciones
```

## ▶️ Uso

Abre `index.html` en tu navegador, o ejecuta un servidor local:

```bash
# Con Python
python -m http.server

# Con Node.js
npx serve
```
